# Fase 1 – Levantamento de Operadores e Palavras-chave do Python

## 🔹 Símbolos

### 1. Operadores Aritméticos
- + (adição)
- - (subtração)
- * (multiplicação)
- / (divisão)
- // (divisão inteira)
- % (módulo/Resto da divisão)
- ** (potência)

### 2. Operadores Relacionais
- == (igual)
- != (diferente)
- > (maior que)
- < (menor que)
- >= (maior ou igual)
- <= (menor ou igual)

### 3. Operadores Booleanos
- and
- or
- not

### 4. Símbolos de Atribuição
- = 
- +=
- -=
- *=
- /=
- %=
- //=
- **=

### 5. Símbolos de Tipos de Dados
- int
- float
- str
- bool
- list
- tuple
- dict
- set

### 6. Símbolo de Início de Bloco
- : (dois pontos)
